# PI2026-2_GerenciadorAtendimentoMultidisciplinar

Frontend em desenvolvimento para o sistema de gerenciamento de atendimentos multidisciplinares do Espaço Bianca Petenão.

## Tecnologias

- HTML
- CSS
- JavaScript

O projeto não utiliza bibliotecas ou recursos externos.

## Etapa atual

Tela de login concluída. A autenticação ainda não está conectada a um servidor.

## Estrutura

- `index.html`: estrutura principal da página
- `style.css`: estilos do projeto
- `script.js`: interações do projeto

**Duração:** 1 dia

**Status:** concluída
